# This project is a JavaScript Assignment that demonstrates core concepts of modern JavaScript including Promises, Async/Await, Fetch API, ES6 Modules, and Local Storage. 
The main purpose of this project is to
understand how asynchronous programming works in real-world applications and how data can be fetched from 
APIs, processed, and displayed in the browser. It also includes a simple mini project where user data is 
fetched from a public API and the selected user is stored in the browser using localStorage.

The project is structured into multiple JavaScript files for better code organization and readability. 
Each file focuses on a specific topic such as handling Promises, working with async/await functions, fetching
data from external APIs, managing browser storage, and using modular JavaScript with import and export.
A basic HTML file is used to connect all scripts and display output in the browser.

Overall, this project helps in building a strong foundation in JavaScript and improves understanding of how 
real-world web applications handle data, asynchronous operations, and client-side storage.
